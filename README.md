# MafiaBazhPors

کنسول اندرویدی فارسی و RTL برای مدیریت حرفه‌ای سناریوی مافیا «بازپرس».

## طراحی
- رابط پریمیوم مشکی/طلایی
- کارت‌های لایه‌ای، گوشه‌های نرم و انیمیشن ورود
- افشای مخفی نقش با تصویر اختصاصی هر نقش
- صفحه کتابخانه نقش‌ها با تصویر و توضیح
- محافظت از اسکرین‌شات و ضبط صفحه با FLAG_SECURE

## بازی
- ۱۲ یا ۱۳ بازیکن
- قرعه‌کشی نقش‌ها
- فاز شب و روز
- ثبت هدف مافیا و نجات دکتر
- استعلام کارآگاه
- ثبت بازپرسی دو نفره
- ثبت شلیک تک‌تیرانداز
- رأی‌گیری دستی با شمارنده و تشخیص مساوی
- ثبت حذف و محاسبه وضعیت پیروزی
- ذخیره وضعیت بازی و ادامه بازی از Home

## Build
Workflow موجود در `.github/workflows/build-apk.yml` با GitHub Actions فایل APK دیباگ را به‌صورت artifact تولید می‌کند.

این نسخه بدون backend و کاملاً آفلاین است.
