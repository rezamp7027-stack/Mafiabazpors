# Restaurant Frontend
فرانت‌اند لوکس و تعاملی یک وب‌سایت رستوران، بدون بک‌اند و بدون فریم‌ورک.

### امکانات
- طراحی RTL، responsive و mobile-first
- Hero سینمایی، navigation sticky و preloader
- منوی تعاملی، دسته‌بندی، جستجو و جزئیات غذا
- سبد سفارش با localStorage
- رزرو میز نمایشی و فرم خبرنامه
- گالری و lightbox
- اسلایدر نظرات و انیمیشن‌های scroll
- Chef's Table، Private Dining، Events، تماس و نقشه نمایشی
- alt/aria/label و کنترل Escape برای modalها

### اجرا
فقط `index.html` را باز کنید یا پروژه را روی یک static host منتشر کنید.

### محدودیت نسخه فعلی
این نسخه فقط Frontend است. رزرو، خبرنامه و پرداخت به سرور/API متصل نیستند و داده واقعی ارسال نمی‌کنند.

### تصاویر
برای نسخه نمایشی از تصاویر منتشرشده روی وب، از جمله تصاویر صفحه‌های عمومی The Charles و منابع تصویری دیگر، استفاده شده است. برای استفاده تجاری یا انتشار رسمی، مجوز هر تصویر را بررسی و در صورت نیاز تصاویر دارای مجوز مناسب را جایگزین کنید.
