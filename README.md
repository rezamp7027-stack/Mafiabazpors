# مافیا | بازپرس — اپلیکیشن اندروید

اپلیکیشن بومی اندروید برای ساخت ترکیب سفارشی و پخش مخفیانهٔ کارت‌های مافیا. این نسخه بدون بک‌اند، حساب کاربری یا اتصال اینترنت کار می‌کند.

## قابلیت‌ها

- تعیین تعداد بازیکنان و تعداد مستقل هر نقش، با تکرار آزاد نقش‌ها
- محاسبهٔ تعداد کارت‌ها و جلوگیری از شروع پخش وقتی تعداد کارت‌ها با بازیکنان برابر نیست
- بانک نقش‌ها با جناح، دسته، توضیح، قابلیت، شرط پیروزی، وضعیت فعال، آیکون و تعداد پیشنهادی
- افزودن، ویرایش، فعال/غیرفعال‌کردن و حذف نقش‌های سفارشی
- ذخیره، بازکردن، ویرایش، کپی و حذف ترکیب‌ها
- تخصیص تصادفی با SecureRandom و تحویل محرمانهٔ کارت به بازیکنان به‌ترتیب صندلی
- صفحهٔ پوشیده برای تحویل گوشی، نمایش جزئیات نقش و پنهان‌کردن آن قبل از بازیکن بعدی
- توقف/ادامه، پخش مجدد با تأیید و بازنشانی دور
- صفحهٔ جداگانهٔ گرداننده برای مرور تخصیص‌ها
- خروجی بانک نقش‌ها و پشتیبان کامل JSON و بازیابی از فایل
- ذخیره‌سازی محلی در SharedPreferences، رابط فارسی RTL و طراحی تیره با جزئیات طلایی

## نقش‌های سناریوی بازپرس

قابلیت رسمی و تأییدنشده‌ای به نقش‌ها نسبت داده نشده است. نقش‌های «بازپرس»، «کارآگاه» و «دکتر» در بانک اولیه قالب قابل‌ویرایش‌اند؛ توضیح و شرط پیروزی معتبر مورد استفادهٔ گروه را در بخش مدیریت نقش‌ها وارد کنید.

## ساخت APK

پروژه با Gradle و Android Gradle Plugin ساخته می‌شود. در محیطی که Android SDK و Java 17 نصب است:

    gradle testDebugUnitTest
    gradle assembleDebug

فایل APK خروجی در مسیر زیر ساخته می‌شود:

    app/build/outputs/apk/debug/app-debug.apk

Workflow موجود در GitHub Actions با هر push به شاخهٔ main تست‌های واحد و ساخت APK را اجرا می‌کند و APK را به‌صورت Artifact قابل دریافت منتشر می‌کند. اجرای workflow نیازمند Android SDK روی سیستم محلی نیست.

## نکات فنی و حریم خصوصی

- نسخهٔ اولیه برای یک دستگاه مشترک و جلوگیری از مشاهدهٔ تصادفی است، نه مقابله با دسترسی فنی به دستگاه.
- داده‌های محلی با حذف داده‌های برنامه ممکن است از بین بروند؛ از JSON برای تهیهٔ نسخهٔ پشتیبان استفاده کنید.
- برای محافظت از حافظهٔ دستگاه، ساخت و پخش بیش از ۱۰۰٬۰۰۰ کارت رد می‌شود.
- این پروژه مجوز شبکه درخواست نمی‌کند و به سرور وابسته نیست.
